# dsh-code-block-quote

**给 DSH 回答里每一个代码块的右上角加一个「引用」按钮。** 点一下，整段代码就作为引用进入输入框，你在它下面接着写问题就行。

DSH 的代码块横幅本来只有一个动作：**复制**。想追问某段代码，只能手动划选——长块很容易漏行，或者把围栏一起选进去。这个插件把缺的那个动词补上。

| 点击后 | 效果 |
| --- | --- |
| 引用按钮 | 整块代码按带语言标签的围栏插入输入框（引用胶囊） |
| 已有草稿 | 引用落在草稿**上方**，你写的内容在后面，不被打断 |
| 鼠标悬停 | 按钮右侧提示「将整段代码作为引用插入输入框」 |
| 插入成功 | 按钮短暂变「已引用」 |
| 发送后的气泡 | **长代码自动折叠**（默认收起至 76px 约 3 行，带渐变半透明遮罩与「展开 ▼ / 收起 ▲」），并**彻底过滤内部坐标乱码**（`※ 引自第 X 轮 │q1:...`） |

## 装什么、不装什么

- **不需要** `dsh-client-ui-quote`，也不需要 `@michengai/dsh-btw`：两者都能**认识**本插件产生的引用块（同一套 `> ❝ ```lang` 线格式），但本插件不依赖它们。
- **不需要任何构建**：纯手写 JS，没有打包器、没有 TypeScript。
- 装了 `dsh-client-ui-quote` 的话，引用会直接进它的引用清单、可加评论、可跳回原文、可导出——属于加成，不是前提。

## 信任边界

- **纯客户端**：宿主侧 `lib/index.js` 是空的 `apply`，不注册路由、不写文件、不发请求。
- **不改宿主代码**：只在渲染出的代码块横幅里插入一个 `<button>`，用 `MutationObserver` 跟随虚拟列表的重建。
- **不改你的草稿语义**：走宿主自己的 `insertReference`（引用胶囊）路径；该路径不可用时退回 `insertText`；两者都失败时只复制到剪贴板并提示，绝不静默丢内容。
- **不执行任何东西**：这个按钮只读代码文本，绝不运行它。

## 引用长什么样

点「引用」后，模型收到的是：

```
> ❝ ``` python
> def greet(name):
>     return "hi " + name
> ```
```

- 围栏语言取自代码块横幅显示的语言标签（`bash`、`python`、`json`…）；无标签时不写围栏信息。
- 代码里本身含 ` ``` ` 时自动改用 `~~~` 围栏，避免提前收尾。
- 行首若以 `\`、`❞`、`※` 开头会被转义，防止被读回成引用语法。
- 末尾空行自动裁掉；行尾空格保留不动的只有内容本身。

## 安装

**桌面端**：设置 → 插件 → 添加插件，填本仓库地址。

**CLI**：

```bash
dsh plugin --profile web add dsh-code-block-quote
# 或从本地目录：
dsh plugin --profile web add link:/path/to/dsh-code-block-quote
```

装完重启 `dsh web`（客户端插件在启动时组装）。

## 已知限制

- 只处理**渲染出来的**代码块。输入框里正在写的草稿、右侧栏文件预览里的代码，不在覆盖范围。
- 引用胶囊的可用性依赖宿主的 `conversation.input.shell(sessionId).insertReference`；宿主降级时按钮仍可用，只是走纯文本插入。
- 虚拟列表滚动时按钮会随代码块一起重建，短暂闪烁属正常的挂载行为。

## 开发

```bash
npm run check            # 两个离线检查一起跑
node scripts/check-client.mjs      # 解析 + 假 DOM 挂载 + 点击 + 卸载
node scripts/check-roundtrip.mjs   # 拿已装的 dsh-client-ui-quote 真解析器回读
node scripts/serve-test.mjs        # 起本地服务看真实浏览器用例
```

`check-client.mjs` 解析 `lib/client.js`、驱动纯函数、用手写假 DOM 挂载插件并模拟点击，断言插入的引用块、来源名、codec 幂等、二次挂载不重复、卸载清干净、含围栏的代码自动换 `~~~`。无第三方依赖。

`check-roundtrip.mjs` 会加载你机器上已安装的 `dsh-client-ui-quote` 的 `__testing.splitQuoteRuns`——也就是转录胶囊渲染器实际使用的那个函数——把本插件的输出喂回去，验证它能还原成**完全相同**的代码和语言标签。覆盖：无标签块、代码含 ```、行首为 `\` / `❝` / `❞` / `※`、行尾空格、缩进、中英混排、纯空白块、引用后接提问。没装 ui-quote 时该检查自动跳过。

`serve-test.mjs` 起一个只读本地 HTTP 服务（默认 8791），打开 `/test/live.html` 在真实 Chromium 里跑同一套断言，页面底部绿色日志即结果，标题变 `PASS dsh-code-block-quote` 表示全过；`/test/preview.html` 是纯视觉预览。
