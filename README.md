# dsh-code-block-quote (DSH 全场景智能引用套件)

**给 DSH 打造的优雅、纯净、全场景引用工作流。**

支持代码块一键引用、全局文本划选弹出 BTW 风格悬浮药丸（可分流发往主对话或侧栏对话）、发送后长引文自动折叠收纳、彻底过滤内部 base64 坐标乱码，并支持重开页面永久双向定位与呼吸光晕高亮。

| 场景 / 功能 | 交互效果 |
| --- | --- |
| **代码块引用** | 代码块右上角新增「引用」按钮，一键把整段代码作为带语言围栏的胶囊插入主输入框上方 |
| **全局文本划选** | 划选聊天正文或代码，自动在选区上方弹出 BTW 风格深色磨砂药丸浮条：`[ 💬 添加到对话 ] [ 📑 侧边对话 ]` |
| **主通道分流** | 点击「添加到对话」：引用插入主输入框，光标自动聚焦，继续在下方写问题 |
| **侧栏分流 (方案 B)** | 点击「侧边对话」：展开右侧栏（`better-sidebar`），直接将引用写入侧栏输入框并聚焦，独立探讨不污染主会话 |
| **发送后的气泡收纳** | 超过 3 行（或 140 字符）的代码自动收起至 76px 紧凑卡片，带渐变半透明遮罩与「展开 ▼ / 收起 ▲」 |
| **内部元数据净化** | 自动过滤掉 `※ 引自第 X 轮 │q1:...` 内部 base64 乱码，告别刺眼全蓝字，恢复舒适代码排版 |
| **重开页面永久定位** | 引用卡片标头显示 `❝ bash · 5 行 · 第 16 轮`，自带 `[ 📍 定位 ]` 按钮；两步粗排+精排，点击平滑居中滚动并带有 1.8 秒呼吸光晕高亮（Flash Highlight） |

## 引用线格式

无论是从代码块还是划选发出，模型收到的都是干净且易懂的自然 Markdown 格式：

```markdown
> ❝ ``` python
> def greet(name):
>     return "hi " + name
> ```
> ※ 第 16 轮
```

- 仅包含极短的人类语言轮次标记（`> ※ 第 16 轮`），坚决不塞进臃肿机器乱码；
- 重新打开会话、导出记录依然可被完全还原并支持精确跳转。

## 信任边界与轻量化

- **纯原生零依赖**：手写原生 JavaScript，无打包器、无外部运行时依赖，打包后仅十几 KB；
- **纯客户端运行**：宿主侧 `lib/index.js` 为空操作，不建立多余网络连接，不修改本地配置；
- **优雅降级**：若未安装或未打开侧边栏，点击侧边对话自动安全提示并复制内容，绝不报错或崩溃。
